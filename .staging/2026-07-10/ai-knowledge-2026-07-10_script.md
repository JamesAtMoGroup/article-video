# 逐字稿 — 本週 AI 大事：Claude Sonnet 5 百萬脈絡上線、ChatGPT 記憶能刪能關、ChatGPT 直接做 PowerPoint

嗨，歡迎來到每日 AI 知識庫。【停頓】

今天是週五，我們照慣例來盤點這一週 AI 圈發生的大事。【停頓】這週很有意思，三家大廠不約而同往同一個方向走——就是把 AI，塞進你原本就在用的工具裡。【長停頓】

先講第一件，Anthropic 推出了新一代模型，Claude Sonnet 5。【停頓】

這次最受矚目的，是它原生支援高達一百萬個 token 的脈絡窗。【停頓】你可以把「脈絡窗」想像成 AI 的一張桌子——桌子越大，它一次能同時攤開來看的東西就越多。過去你丟一份很長的文件給 AI，它常常看了後面就忘了前面，就是因為桌子不夠大，塞不下。【停頓】現在這張桌子大幅變大，整份合約、整個專案的程式碼，都能一次攤開來前後對照。也因為這樣，它特別適合寫程式這種要理解整個專案結構的工作，這也是為什麼 Anthropic 直接把它設成 Claude Code 的預設模型。【長停頓】

那這對我們有什麼意義呢？【語氣：疑問】這代表你可以嘗試「把一大包東西一次餵進去」的用法——像是整份會議逐字稿、一整章教材、好幾封往來郵件——請它跨段落幫你統整。【停頓】不過這裡有個素養提醒——脈絡窗變大，不等於它「記得住一切」，也不等於它「一定不出錯」。【語氣：強調】內容越多，你越應該在關鍵結論上，抽查它到底有沒有讀對。而且更長的輸入，通常也意味著更高的花費，長，不代表免費。【停頓】

那換你想一想——如果 AI 一次能讀完你手邊那份最長的文件，你第一個想請它幫你做的事，會是什麼？【長停頓】

接著講第二件，這件我覺得每個人都該學起來。ChatGPT 這週把「記憶」的控制權，進一步交回到使用者手上。【停頓】

現在你可以在記憶摘要頁上，刪除單獨一則被記住的內容，也可以直接把整個記憶功能關掉。【停頓】這個控制先在網頁版對所有使用者開放，手機版隨後陸續推出。【停頓】

為什麼這件事重要？【語氣：疑問】「記憶」是這一兩年聊天機器人很主打的功能，它會記住你的習慣、稱呼、偏好，讓對話越用越順手。【停頓】但這是一把雙面刃——它記住的東西，你未必記得它記了。那些記錯的、過時的、你根本不想被記住的，都可能一直影響它之後給你的回答。【停頓】所以給你一個「看得到、刪得掉、關得掉」的開關，其實就是把資料的主導權，還給你自己。【長停頓】

我很建議你，找個時間打開記憶摘要頁看一眼，你可能會很驚訝它到底記了哪些事。【停頓】處理敏感話題的時候，像是健康、財務、工作機密，可以考慮先把記憶關掉，或用不記憶的模式；如果發現它老是拿某個過時資訊來回答你，直接把那一條刪掉就好。【停頓】記住一句話——工具越貼心，你就越要知道，它在背後幫你留了什麼。【停頓】

想一想——如果現在打開 ChatGPT 的記憶清單，你會希望裡面「不要有」哪一類關於你的資訊？【長停頓】

最後第三件，也跟「工具融合」有關。OpenAI 讓 ChatGPT for PowerPoint，正式對企業版工作區全面開放。【停頓】

它的重點是——你可以直接在 Microsoft PowerPoint 裡面，用 ChatGPT 生成跟修改「可以編輯」的投影片。【語氣：強調】注意是可以編輯的投影片，不是一張改不動的圖片。【停頓】

為什麼這是個進步？【語氣：疑問】過去用 AI 做簡報，常常卡在最後一哩路——AI 給你一份草稿或圖檔，你還是得回到 PowerPoint 重排、改字、調格式。【停頓】現在把助手直接嵌進簡報軟體，等於把「生成」跟「編修」接在同一個地方，省掉兩邊來回搬運。而且產出的是原生、可以繼續編輯的投影片，你能照公司的格式接著微調，這才是能不能真正拿去用的關鍵。【長停頓】

不過一樣提醒——別把它當成一鍵交差。【語氣：強調】AI 生出來的簡報，架構跟數字，還是要你自己把關，尤其是要對外報告的內容。它幫你省掉的是排版跟起草的體力，但「這一頁到底想講什麼」，還是得由你來決定。【停頓】

想一想——你最近一次做簡報，最花時間的是「想內容」，還是「調格式」？哪一段你最想交給 AI？【長停頓】

好，我們把今天的三件大事整理一下。【停頓】

第一，Claude Sonnet 5 上線，帶來原生百萬 token 的脈絡窗，還成了 Claude Code 的預設模型；它能一次讀更多，但記得，長不等於免費，也不等於不會出錯。【停頓】

第二，ChatGPT 的記憶現在能逐條刪除、也能整個關掉；這是一個把資料主導權拿回自己手上的關鍵素養動作，強烈建議你去點開看看。【停頓】

第三，ChatGPT for PowerPoint 對企業版正式上線，讓你直接在簡報軟體裡生成可編輯的投影片；它幫你省下排版的體力，但內容還是要你把關。【長停頓】
