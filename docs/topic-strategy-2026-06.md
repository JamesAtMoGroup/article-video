# 每日 AI 知識庫 — 選題策略（v1, 2026-06-02）

> 依據：Kolable 後台 39 集觀看數據（2026-04~05）。本檔為 SKILL.md Step 2B 選題的決策依據。
> SKILL.md 已將「類別比例 / 標題公式 / 禁止公式 / 題目庫 / actionable 收尾」內建為產製規範。

## 核心結論

- 平均每集觀看率 21.6%（63 人母數）/ 59.1%（23 付費母數）。
- **5 月觀看率較 4 月衰退 37%（27%→17%）** = 首要問題 → 對策：每集 actionable 收尾、series 綁集、冷集重發、LINE bot 回流。
- 爆款 DNA = 擬人化 + 反常識 + 新興名詞解謎。
- 失敗模式 = 技術內裡 + 學員無法立即用（Embedding、評估指標等一律砍）。

## 量化目標

| 時間 | KPI |
|---|---|
| 1 個月 | 平均觀看率 21.6% → 30%；0 人看集數維持 0 |
| 3 個月 | 60% 付費學員每週看 ≥ 3 集 |
| 6 個月 | 應用實戰類累積 ≥ 30 集（目前 3 集） |

## 跨系統對齊（待辦，非本 skill 範圍）

1. claude-line-bot：每日推「今日新片」+ 看完 24h 推 follow-up prompt。
2. blog 文字版同步發（SEO + 捕回不看影片的學員）。
3. 業師健檢個別推薦「你的工作這 3 集最有用」。

## 可再 deep dive 的維度

學員維度（誰看最多/流失/冷學員預警）、真實完成率（progress ≥ 0.8）、觀看時效（24h/7d/30d）、跨課程黏著度比較。
